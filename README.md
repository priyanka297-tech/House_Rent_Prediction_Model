# 🏠 House Rent Prediction System

An end-to-end Machine Learning web application that predicts monthly house rent based on property details such as BHK, size, city, furnishing status, house age, floor ratio, and tenant preference.

The application is built using **Python**, **Scikit-learn**, and **Streamlit**, providing an interactive dashboard for data exploration, visualization, model evaluation, and real-time rent prediction.

---

## 🚀 Features

- 🏠 Predict monthly house rent using Machine Learning
- 📊 Interactive Exploratory Data Analysis (EDA)
- 📁 Dataset Overview
- 📈 Correlation Heatmap & Visualizations
- 📉 Model Performance Evaluation
- 🤖 Random Forest Regression Model
- 🎨 Professional Streamlit Dashboard

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/House_Rent_Prediction.git
```

Navigate to the project folder

```bash
cd House_Rent_Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
